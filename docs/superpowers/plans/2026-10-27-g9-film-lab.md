# G9 Film Lab Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and deploy a functional original-DC-G9 recipe library, setup guide, editor, local recipe shelf, comparison tool, and protected editorial admin.

**Architecture:** Separate the G9 capability engine, recipe data/repository, browser-only preview and local library, and route-level UI. Neon is the Postgres provider, Neon Auth is the admin identity provider, and Vercel Blob stores approved public photographs.

**Tech Stack:** Next.js App Router, React, TypeScript, Tailwind CSS, shadcn/ui, Lucide, Neon Postgres, Neon Auth/Better Auth integration, Vercel Blob, Zod, Vitest, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-27-g9-film-lab-design.md`

## Global Constraints

- “The original DC-G9 is not the G9 II.”
- “Do not offer LUT files as though they can be imported into the original G9.”
- “Do not claim that the website can directly install recipes into the camera.”
- “Treat camera settings-file generation as experimental until independently verified on original DC-G9 hardware.”
- “No recipe may receive a verified badge without documented camera testing.”
- “The preview is only an approximation. It is not Panasonic’s internal JPEG processing pipeline.”
- “Personal recipes survive page reloads” through browser persistence and backup export/import.
- Keep DB credentials, auth secrets, and Blob write tokens server-side.
- Use original or appropriately licensed example photography; never call a generic image a G9 capture.

## Review Focus

- Unsupported or firmware-gated Photo Style controls must be rejected by the shared validator and shown with useful errors.
- A monochrome recipe must not silently accept colour saturation, and a colour recipe must not silently accept monochrome-only grain/filter controls.
- An anonymous or signed-in non-admin visitor must never write recipe publication data or upload editorial assets.
- Filter parameters and local recipes must survive refresh, URL sharing, offline reload where cached, and malformed imports without corrupting saved data.
- A preview must never pair different source scenes or be represented as camera-verified.
